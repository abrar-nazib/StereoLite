local PDFs (see `papers/raw/`) at 200 dpi using PyMuPDF. Each crop includes the figure

## Notes / caveats

- All 20 target figures were found on the primary or secondary candidate figure within
  pages 1-6 of each PDF; no fallback papers (StereoNet, AnyNet, DLNR) were needed.
- **MonSter** (#20): the file on disk is the extended MonSter++ manuscript rather than the
  original CVPR 2025 short paper, so the diagram is labeled "Fig. 5: Overview of MonSter++"
  in the crop rather than "Fig. 2". Architecturally it is the correct whole-network
  dual-branch (mono depth + stereo + mutual refinement) diagram the task asked for.
- **LiteAnyStereo** (#15): used Figure 3 ("Overview of the proposed Lite Any Stereo"), the
  network-architecture diagram, not Figure 4 which is a separate 3-stage-training-strategy
  diagram in the same paper.
- Every crop was produced via: locate the caption text ("Figure N" / "Fig. N" match,
  filtered to captions mentioning overview/architecture/pipeline/framework/network/
  illustration/structure/diagram) -> union bbox of `get_drawings()` + `get_image_info()`
  content above the caption -> `page.get_pixmap(clip=..., dpi=200)` -> visually verified
  via direct image read to confirm it is the whole-network diagram and not a results grid,
  qualitative comparison, or loss curve.
